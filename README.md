# Trading card scan images

This repository contains the public JPG scans for the processed trading card series.

The image base URL for listings is:

`https://rico13187.github.io/trading-card-scans/images/`

Filenames follow the pattern `ID_Spieler_Serie_Seite.jpg`, where `Seite` is `1` for the front and `2` for the back.
The workbook in the local collection folders contains the matching front and back links.
